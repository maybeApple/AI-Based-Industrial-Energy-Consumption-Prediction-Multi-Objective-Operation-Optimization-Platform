# Data provenance

`operations_demo.csv` is generated by `api/industrial/data.py`, seed 42, 6000 observations at 15-minute intervals. All machine and energy variables are synthetic. No production variables are fabricated from UCI energy targets. SIM-ROLL-01 is a simulated machine, not connected hardware.

`Steel_industry_data.csv` is the unmodified UCI Steel Industry Energy Consumption dataset, downloaded by `scripts/prepare_industrial.py` (35,040 observations).

Attribution: V E, S., Shin, C., & Cho, Y. (2021). Steel Industry Energy Consumption [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C52G8C. License: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ . Source: https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption .

The UCI dataset does not contain machine speed, continuous machine load, temperature or production rate. It supports a separate rolling one-step forecasting benchmark; it does not validate the operating optimizer. `steel_test_preview.csv` is a derived chronological test-set prediction extract; original data attribution applies.

`dynamic_transitions.csv` is a separate V1.2 dataset generated by `api/industrial/plant.py`: 180 simulated dynamic trajectories of 50 transitions each. The entire last 36 trajectories are held out for ANN evaluation. No UCI measured variables are used to fabricate the dynamic states. It includes current states, commanded actuators, ambient/material inputs, next states and episode IDs. Source: synthetic_dynamic_plant.
